# Proxmox Setup

This section is for the part that happens before the lab feels routine.

It covers the host itself: the machine, the firmware choices, the install path, and the first configuration decisions that are much easier to get right early than to quietly regret later.

Use this section when the question is not "what is Proxmox?" but "how do I stand this host up cleanly in the first place?"

## What Belongs Here

- host installation and initial bring-up
- pre-deployment drive validation when reused disks are part of the plan
- BIOS and virtualization settings
- first-pass storage and network choices
- power-management choices that affect how the host can be recovered later
- hardware-specific setup that shapes the platform before workloads land on it

## In This Section

- [Used Drive Validation Before Deployment](/pages/proxmox/setup/used-drive-validation) — the destructive preflight for second-hand disks before they earn a place in Proxmox, TrueNAS, or any other pool you would rather not rebuild.
- [How I Build A Node Now](/pages/proxmox/setup/building-a-node) — how my nodes are built today: a ZFS mirror, an out-of-band VLAN with no internet, and a playbook for everything after the installer.
- [Homelab Installation](/pages/proxmox/setup/homelab-installation) — my first install, Proxmox VE 8 on a flat home network: BIOS choices, installer path and storage layout. Kept as it was.
- [Dual Boot: Proxmox & Rocky Linux](/pages/proxmox/setup/rocky-linux-dual-boot) — a Rocky Linux proving ground next to Proxmox on the same NVMe drives. Retired: no host runs Rocky Linux now.

## How To Read It

Start here when you are building or rebuilding a node.

If used disks are part of the storage plan, read [Used Drive Validation Before Deployment](/pages/proxmox/setup/used-drive-validation) before you let those drives near a production pool. Then read [How I Build A Node Now](/pages/proxmox/setup/building-a-node) for the node itself.

[Homelab Installation](/pages/proxmox/setup/homelab-installation) is the simpler first install. For one host on a home network, its BIOS settings and installer steps are still a good start.

If remote recovery matters, pair that bring-up with [Wake-on-LAN For Proxmox](/pages/hardware/jetkvm/wake-on-lan-for-proxmox) before you lock down the final firmware and power settings.

If you are still deciding whether Proxmox is the right base at all, go back to [Proxmox Basics](/pages/proxmox/basics) first. If the host already exists and you are trying to operate or extend it, continue into [Proxmox Operations](/pages/proxmox/operations) or [Self-Hosted Services](/pages/services).
